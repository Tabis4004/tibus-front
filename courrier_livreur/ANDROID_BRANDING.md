# Android branding

L'application Android générée depuis `courrier_livreur` doit s'installer sous le nom **Tibus Livraison**.

Le label est défini dans `android/app/src/main/AndroidManifest.xml` :

```xml
android:label="Tibus Livraison"
```

Si le dossier Android est régénéré avec `flutter create .`, conserver ce label avant de publier sur Play Store.
